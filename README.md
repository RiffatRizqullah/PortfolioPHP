# Portfolio — Riffat

This is a small PHP-based portfolio scaffold with HTML, CSS, and JS. It includes a simple contact form that appends messages to `data/messages.txt`.

Run locally using PHP's built-in server:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

Files added:
- `index.php` — main page and form handler
- `assets/css/style.css` — styles
- `assets/js/main.js` — small JS utilities
- `assets/images/*` — SVG placeholders
- `data/messages.txt` — stored messages (created empty)

Replace images, projects, and text with your own content.
